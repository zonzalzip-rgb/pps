# 쇼핑 쇼츠 제작 스킬 V12

상품 페이지와 타겟 영상을 바탕으로 TikTok 실사 소스를 편집해 한국어 쇼츠를 제작합니다. 검색은 TikTok 안에서 중국어 간체 상품명만 사용합니다. 영상 원본 자막은 강하게 블러한 뒤 준비된 씬별 WAV 나레이션, 한국어 자막, 제품번호 배너를 합성합니다.

## 설치

Python 3.10 이상에서 다음 명령을 실행합니다.

```powershell
python setup.py
```

Python 패키지와 필요한 Vosk 모델·주아체 글꼴을 설치합니다. 별도로 ffmpeg와 ffprobe가 필요합니다. PATH에 등록하거나 `FFMPEG_BIN`, `FFPROBE_BIN` 환경변수를 지정합니다.

## 작업

`SKILL.md`를 기준으로 진행합니다. 나레이션 WAV는 씬마다 준비해 `audio/01.wav`, `audio/02.wav`처럼 저장합니다. 이 패키지는 TTS 생성을 제공하지 않습니다. 제품별 결과 폴더에 MP4, 썸네일 4장, 메타데이터 TXT를 저장하고 영상 결과물을 ZIP으로 압축하지 않습니다.

외부 서비스 API, API 키, `.env` 설정은 사용하지 않습니다. 상품 확인 URL을 기록하며, 제휴 링크는 사용자가 직접 준 경우만 표시합니다.
