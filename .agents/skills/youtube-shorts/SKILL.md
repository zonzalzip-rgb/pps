쇼핑 쇼츠 제작 V12
이 스킬은 사용자가 제공한 상품 정보와 준비된 한국어 WAV 나레이션으로 30초 미만 세로 쇼츠, 썸네일, 메타데이터를 로컬에서 만든다. 외부 서비스 API 연결이나 API 키 입력을 요구하지 않는다. TTS 생성은 포함하지 않으므로 씬별 WAV 음성을 준비해 프로젝트의 `audio/NN.wav`에 넣는다.
설치와 작업 경로
스킬 폴더의 `setup.py`를 한 번 실행한다. Python 3.10 이상, ffmpeg, ffprobe가 필요하다. ffmpeg가 PATH에 없으면 `FFMPEG_BIN`과 `FFPROBE_BIN` 환경변수로 실행 파일 경로를 지정한다. 중간 파일은 `COUPANG_SHORTS_PROJECT`로 지정한 폴더의 `output/` 아래에 둔다.
1단계: 설정과 상품 확인
이미 사용자가 제공한 정보는 다시 묻지 않는다. 부족한 경우에만 다음을 하나씩 받는다: TikTok 자동검색 또는 사용자가 제공한 TikTok 링크, 제품번호, 썸네일 두 줄 문구, 타겟 쇼츠 링크, 씬별 WAV 나레이션.
타겟 쇼츠와 상품 페이지를 확인하고 상품명·형태·색상·재질·구성·사용 방법을 기록한다. 상품 정보는 확인된 내용만 사용한다.
2단계: TikTok 검색과 영상 수집
자동 검색은 TikTok에서만 한다. 검색창에는 상품을 특정하는 중국어 간체 상품명만 입력한다. 한국어, 영어, 브랜드의 라틴 문자 표기, 해시태그를 섞지 않는다. 브랜드명이 필요하면 중국어 음역을 사용한다. 예: `自动削苹果机 电动水果削皮器`, `舒尼尔防滑浴室拖鞋 低鞋面`.
TikTok 검색 결과에서 상품 페이지의 기준 이미지와 여러 프레임을 비교한다. 다른 모델, 일반적인 카테고리 영상, 상품이 제대로 보이지 않는 영상은 제외한다. 원본이 9:16인 실사 영상만 사용하고 해상도·비율·재생 여부를 확인한다. 중복을 제외해 상품당 5~12개를 확보한다. 5개 미만이면 성공으로 처리하지 말고 중국어 검색어와 실패 사유를 기록한다. 직접 링크 모드는 사용자가 준 TikTok 링크만 사용한다. 다른 플랫폼의 영상이나 생성형 영상·이미지는 소스로 사용하지 않는다.
3단계: 대본과 음성 파일
타겟 영상의 후킹, 문제 제기, 시연, 장점, 마무리 흐름을 참고해 문장을 새로 쓴다. 타겟 문장을 그대로 복사하지 않는다. 4~6개 씬, 총 30초 미만으로 구성한다. 씬마다 대본과 길이가 맞는 WAV를 준비해 `audio/01.wav`부터 순서대로 저장한다. 모든 음성은 로컬 파일로만 읽는다.
4단계: 컷 편집과 강한 원본 자막 블러
각 씬의 WAV 길이에 맞춰 원본 클립과 시작 시점을 정한다. 컷 편집 영상에서 원본 오디오는 제거한다.
한국어·영어·중국어·일본어 등 영상 원본에 이미 들어간 자막만 OCR로 찾아 블러한다. V12의 기본 블러는 Gaussian 커널 81 이상, 마스크 불투명도 0.98 이상으로 적용해 원문을 읽을 수 없게 한다. 자막 위치와 표시 시간에 맞춰 마스크를 추적하고, 꼭 필요한 최소 여백만 둔다. 블러가 약하거나 글자가 보이면 해당 구간을 확인해 더 강하게 보정한다.
글자 윤곽을 벗어난 화면 가로 띠, 자막 줄 전체를 덮는 넓은 막대는 금지한다. 상품, 제품 인쇄, 배경, UI는 원본 자막이 아닌 한 선명하게 둔다. 씬 전체에서 여러 시점의 clean 프레임을 확인하고 글자가 남거나 주변 화면까지 과도하게 흐려진 경우 위치와 시간 범위를 조정해 다시 처리한다. OCR 또는 디코더 오류가 있으면 다음 단계로 넘어가지 않는다.
5단계: 자막 합성, 배너, 렌더
블러 검수를 통과한 뒤에만 한국어 대본 자막을 합성한다. 주아체 중앙 카라오케 스타일을 사용하고 말하는 단어를 강조한다. 영상 상단에는 `제품번호: NN` 배너를 넣는다. 결과는 9:16, H.264/AAC MP4, 30초 미만, 무음 원본 오디오와 준비된 나레이션으로 만든다.
6단계: 썸네일과 메타데이터
완성 영상에서 서로 다른 핵심 장면 4개를 골라 9:16 썸네일을 만든다. 윗줄은 하늘색, 아랫줄은 흰색, 굵은 외곽선의 기존 주아체 스타일을 쓴다.
제목·상품 설명·태그·상품 확인 URL을 UTF-8 텍스트 파일로 저장한다. 확인하지 않은 성능을 단정하지 않는다. 제휴 링크는 사용자가 직접 제공한 경우에만 표시하고, 그 외에는 상품 확인 URL만 기록한다. API 호출이나 API 기반 링크 변환은 하지 않는다.
7단계: 정리와 검수
제품번호와 상품명으로 폴더를 정리하고 MP4, 썸네일 4장, 메타데이터 파일이 있는지 확인한다. 영상을 재생해 화면비, 길이, 음성, 자막 블러를 확인한다. 완성 영상이나 결과 폴더는 ZIP으로 만들지 않는다.
파일 규칙
최종 영상: 9:16, 30초 미만, 준비된 WAV 나레이션 포함, TikTok 원본 소리 제거
TikTok 검색어: 중국어 간체 상품명만
원본 자막: 강한 Gaussian 블러, 상품과 배경은 가능한 한 선명하게 유지
결과물: MP4, 썸네일 4장, 메타데이터 TXT를 제품별 폴더에 저장
외부 API 키, API 호출, `.env` 설정 파일 사용 금지
