# AGENTS.md — 쇼핑 쇼츠 제작 V12

전체 작업 규칙은 `SKILL.md`를 따른다.

## 실행 요약

1. 사용자가 준 상품과 타겟 영상을 확인한다.
2. TikTok에서 중국어 간체 상품명만 검색한다. 한국어·영어·라틴 문자 브랜드를 검색어에 넣지 않는다.
3. 서로 다른 9:16 실사 TikTok 원본 5~12개를 검증하고 상품 일치도를 확인한다.
4. 4~6개 씬의 새 한국어 대본과 WAV 음성을 준비한다. API TTS는 사용하지 않으며 WAV 파일은 `audio/NN.wav`에 둔다.
5. `blur_text.py`로 원본 자막에 강한 블러를 적용한다. 기본 Gaussian 커널은 81 이상이며, 글자가 읽히지 않는지 여러 프레임을 확인한다. 블러는 원본 자막에만 맞추고 제품과 배경은 선명하게 유지한다.
6. 검수된 clean 클립에만 한국어 자막, 제품번호 배너, TTS 음성을 합성한다.
7. 썸네일 4장과 제목·설명·태그·상품 URL 텍스트 파일을 만들고 최종 MP4를 재생 검수한다.
8. 결과물을 제품별 폴더에 정리한다. 영상 완성물은 ZIP으로 만들지 않는다.

외부 서비스 API와 API 키 설정은 사용하지 않는다. 쿠팡 제휴 링크는 사용자가 직접 제공한 경우만 기록한다.
